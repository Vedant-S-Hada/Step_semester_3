# Step_semester_3

This repository now includes:
1. Java practice programs for semester work.
2. A pitch-ready Futurix website built from scratch.

## Programs

- `GCD.java` - Finds the greatest common divisor of two numbers.
- `PrimeCheck.java` - Checks whether a number is prime.
- `PalindromeCheck.java` - Checks whether a number is a palindrome.
- `TrianglePattern.java` - Prints a triangle number pattern.
- `ArmstrongCheck.java` - Checks whether a number is an Armstrong number.

## Futurix Website

- `index.html` - Main single-page website structure and content.
- `styles.css` - Modern responsive styling and visual theme.
- `script.js` - Mobile menu, reveal animations, and footer year logic.

### Run locally

Open `index.html` directly in a browser, or serve the folder with a local server.
